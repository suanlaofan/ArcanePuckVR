# Arcane Puck VR v1.0.3

2026-09-07：改进 PICO 手柄灵敏度、玩家桌边定位、编辑器鼠标预览及 PICO 模拟器输入。

- 手柄改为相对中立位映射，倍率可选 2.0 / 2.5 / 3.0，默认 2.5；接近边界后反向立即响应。
- 默认将玩家定位在近侧桌边 0.45m，可切换距离、主手和站/坐姿，支持重新定位与追踪丢失暂停。
- 开始/暂停菜单保留灵敏度等设置；编辑器 VR 预览默认支持鼠标移动、点击及蓄力。
- 修复 PICO 模拟器产品名不含 emulator 时的漏判，增加虚拟手柄朝向到球槌目标和菜单点击的输入路径。
- 保留正式场景的模型调整，APK 使用已有 Arcane Puck 游戏图标。
- 提交本次已构建和测试的物理设置（零重力、低速弹性阈值、8/4 次求解迭代）及 Unity 保存的线性光照设置，以记录发布构建实际状态。

## 验证

- Unity 6000.5.4f1：EditMode 45/45、PlayMode 15/15 通过。自动测试覆盖映射、定位、正式场景交互、鼠标与菜单射线回归。
- Android ARM64 / IL2CPP / Vulkan Development APK 构建、ZIP 完整性和 APK v2 签名通过。
- 安装至 PICO 0.13 模拟器，回拉的安装包与发布 APK 哈希一致。用户随后确认“可以了”并授权发布；这是用户操作确认，未声称由自动化完成了全部宿主鼠标验收。
- APK 内 legacy、round、adaptive 图标资源已核验为游戏图案。PICO 真机手感、双目舒适度和性能尚未验收。
